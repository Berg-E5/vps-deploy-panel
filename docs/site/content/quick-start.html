先备份测试 VPS

本版会使用已审核的远程高权限安装脚本；请先使用临时、可快照或可重装的 Debian / Ubuntu VPS。

第 1 步：添加 VPS

  • 打开本控制台，点击右上角 添加 VPS。
  • 输入易识别的名称、服务器公网 IP、SSH 端口（默认 22）、SSH 用户（自动安装目前要求 root）。
  • 如果已有域名需要签 HTTPS 证书，再填写 HTTPS 证书域名；没有域名可以留空。
  • 选择 SSH 密码或私钥登录，保存后继续下一步。

第 2 步：SSH 主机指纹

面板会扫描 SSH 主机公钥并显示 SHA-256 指纹。请在云厂商独立可信控制台查看服务器公钥指纹，两边一致后再点击确认；不要只凭本控制台自己显示的结果就信任。

# 在 VPS 云厂商的原生终端中运行（示例为 ED25519）：
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

若服务器使用 RSA / ECDSA，按提示选择对应的 /etc/ssh/ssh_host_*.pub。曾经信任且未变化的指纹可直接继续；VPS 重装后出现变化，必须重新独立核对。

第 3 步：测试 SSH 连接与系统

点击环境检测。系统会确认发行版、CPU、root 权限、磁盘、systemd、端口占用和已安装组件；检测失败会在当前步骤说明原因，无需返回主页重新添加。

第 4 步：端口与防火墙（可跳过）

可以先只查看 UFW 状态。需要开放端口时点击 ＋ 添加端口，逐条填写 TCP/UDP，最后点 一次放行全部端口。如果你还没确定要开放哪些端口，点击 跳过此步，直接进入下一步。

云平台还有一层独立的安全组 / VPC 防火墙；本机 UFW 规则不等于公网自动放行。详见 端口与防火墙。

第 5 步：选择要部署的项目

项目库最前面是自己维护的两个项目，其余是内置的开源项目。

自建项目

  • 物流报价系统 —— 多用户物流报价计算与改价后台。需要填站点域名；装完是空站，登录 /admin 后在后台上传报价表 xlsx 才有价格。详细步骤见 部署指南。
  • 音乐解锁工具 —— 浏览器端本地解锁。只需站点域名，纯静态站，没有后端也没有常驻服务。详细步骤见 部署指南。

内置项目

3X-UI、S-UI、sing-box、wg-easy、Dockge Apps 等。系统会识别现有安装并生成计划，先展示兼容性要求、具体命令和风险，再由管理员审核批准。Hysteria2 当前仍为引导方案，不能当作完整自动安装。

任务执行完成后

到 最近任务 查看状态与分步骤日志。

  • 物流报价系统：任务日志里会打印首次启动随机生成的 admin 密码；用 http://你的域名/admin 登录后，在后台「整表导入」上传报价表 xlsx，约 2～3 分钟生成全部价格，前台立即可用。
  • 音乐解锁工具：浏览器打开 http://你的域名 即可使用，解密在浏览器里完成，文件不上传服务器。
  • 支持展示初始凭据的面板项目（3X-UI、S-UI），可点 查看面板信息 按需读取 VPS 上的初始凭据。
任务失败怎么办

先对照 常见问题，不要在原 VPS 上盲目重复安装。不同版本的固定脚本变更后应刷新旧审批方案。
