在浏览器里管理 VPS，部署自己的项目

面板跑在你自己的电脑上。添加服务器、核对 SSH 指纹、检查环境、生成部署方案、审批执行 —— 每一步都留在任务记录里，不会在你不知情的情况下对服务器执行远程命令。

安装面板 →五步完成第一次部署
这是 Alpha 测试版

当前主要在 Windows 11 本机面板与 Debian / Ubuntu 测试 VPS 上验证。请先在可以重置的服务器上试用，不要把未经验证的任务直接放到重要生产业务上。

第一次使用从这里开始

01 · 安装面板准备 Git 和 Python，Windows 一条命令启动；之后更新不丢数据。 02 · 五步完成第一次部署服务器信息 → SSH 指纹 → 系统检测 → 端口与防火墙 → 选择项目。 03 · 部署自己的项目物流报价系统与音乐解锁工具的完整流程、条件与验收方式。 04 · 常见问题页面打不开、指纹变化、SSH 超时、证书申请失败时怎么排查。

面板能做什么

▤ 服务器与 SSH 管理保存服务器记录、测试连接、核对主机指纹、重装后重新建立信任。 ⬡ TCP / UDP 端口批量放行 UFW 规则，或直接打开云厂商安全组配置页。 ⬢ 项目部署两个自建项目排在最前，其余是 3X-UI、S-UI、Dockge Apps、sing-box、wg-easy 等常用开源项目。 ◈ 数据与安全边界本机运行、审批机制、凭据保管方式，以及目前明确不支持的场景。

部署是怎么执行的

添加 VPS→核对指纹→环境检测→可选网络配置→生成方案→审批执行

面板不会「点一下就不经确认地运行远程命令」。它先检查系统版本、端口占用和已有安装，再生成一份可逐行查看的固定脚本；你确认之后才会在服务器上执行。执行过程和每一步的输出都记录在任务页面里。

方案在审批前会再跑一次环境检测。如果服务器状态在这期间变了 —— 比如端口被别人占了、目标程序已经装好了 —— 面板会拒绝执行并要求重新生成方案。

面板里有哪些项目

物流报价系统多用户物流报价计算与改价后台，装完是空站，需在后台上传自己的报价表才有价格。 音乐解锁工具浏览器端本地解锁，解密过程在浏览器里完成，文件不上传。 3X-UI / S-UI支持 IP 或域名证书，也支持交给 Nginx Proxy Manager 统一处理 HTTPS。 Dockge Apps 应用中心从固定源码构建的 Docker 镜像，含 Nginx Proxy Manager、IT-Tools、MyIP。

外观与阅读

右上角的 ◐ 主题可以切换明亮 / 暗黑 / 跟随系统三种外观，并选择经典蓝、极光紫、海洋青、翡翠绿、玫瑰粉、暖日橙六种主题色；同一个菜单里还能调整阅读字号（标准 / 舒适 / 大字）。这些设置只存在本机浏览器里，不写进面板数据库，也不会带上 SSH 凭据或账号信息。
