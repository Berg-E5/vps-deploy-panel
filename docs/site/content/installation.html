推荐方式：Windows 11 本机运行

本控制台是在你自己的电脑上打开的 Web 管理面板，默认访问地址为 http://127.0.0.1:8787。你的 VPS 不需要安装本控制台本体。

方式一：安装包（普通用户推荐）

下载 VPSDeployPanel-<版本>-Setup.exe 双击安装即可。不需要预先装 Python，也不需要装 Git。

  • 安装包自带 Python 运行时和全部依赖，装完约 110 MB。
  • 装到 %LOCALAPPDATA%\Programs\VPS Deploy Panel，不需要管理员权限。
  • 开始菜单和桌面都有快捷方式，双击就启动面板并自动打开浏览器。
  • 勾选「登录时自动启动」会登记一个计划任务，登录系统后面板自动可用。
  • 卸载：设置 → 应用 → VPS Deploy Panel。会停掉后台进程并移除计划任务。

面板只监听 127.0.0.1:8787，不对外网开放。

数据不在安装目录

服务器配置、任务记录、日志和本机令牌都放在 %LOCALAPPDATA%\VPSDeployPanel。覆盖升级不会丢数据；卸载默认保留这份数据，重新安装后直接接着用。

方式二：从源码运行（要改代码的人）

  • 电脑：Windows 11，能访问 GitHub。
  • 安装 Git for Windows 和 Python 3.12 或以上版本，需有 Windows py 启动器。
  • 预备一台 Debian / Ubuntu 测试 VPS，能够通过云厂商控制台独立查看 SSH 指纹。

一条命令安装与启动

打开 Windows PowerShell，复制以下整行。脚本会在桌面创建或复用 vps-deploy-panel-git 目录，检查 GitHub 来源、更新代码、安装依赖，再启动面板。

$repo=Join-Path ([Environment]::GetFolderPath('Desktop')) 'vps-deploy-panel-git'; if(-not(Test-Path $repo)){git clone https://github.com/Berg-E5/vps-deploy-panel.git $repo; if($LASTEXITCODE -ne 0){throw 'Git clone failed'}}; $start=Join-Path $repo 'scripts\QuickStart-Windows.ps1'; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $start

启动成功后，浏览器通常会自动打开 http://127.0.0.1:8787。桌面出现的 vps-deploy-panel-git 是本机工作目录，不是 VPS 数据目录。

首次启动不需要手填面板令牌

Windows 单机快捷启动可自动创建本机管理员令牌并启用环回地址自动登录；VPS SSH 密码仍必须单独提供。

以后怎么重新打开？

安装包方式：双击桌面或开始菜单里的 VPS Deploy Panel 快捷方式。面板已经在运行就直接打开网页。

源码方式：进入桌面 vps-deploy-panel-git，双击 QuickStart-VPSDeployPanel.bat。面板已运行时直接打开网页，停止后双击则检查更新并在后台启动。

若提示 8787 已被占用，先停掉旧的进程再重新启动；不要用两个进程同时操作同一数据库。

更新软件，不丢原有数据

安装包方式：下载新版安装包并覆盖安装即可，用户数据在 %LOCALAPPDATA%\VPSDeployPanel，不会被覆盖掉。

源码方式：推荐先停止旧服务，再双击 QuickStart-VPSDeployPanel.bat；也可运行 Update-VPSDeployPanel.bat 更新后用 Start-VPSDeployPanel.bat 启动。更新器会保留原有的本地配置、任务数据库、可信 SSH 主机密钥，并对本地数据执行备份。

更新后在浏览器按 Ctrl+F5 强制刷新。右上角版本号与 /api/health 返回的版本应一致；否则可能仍在运行旧进程。

Docker / NAS 用户

适合熟悉 Docker 的用户。需要 Docker Engine、Docker Compose v2 和可以写入数据目录的权限。管理页面默认仅映射到宿主机 127.0.0.1:8787，不要直接映射到公网。

  1. 下载项目并准备本地配置：
git clone https://github.com/Berg-E5/vps-deploy-panel.git
cd vps-deploy-panel
mkdir -p data secrets
cp .env.example .env

编辑 .env，把 VPSDEPLOY_ADMIN_TOKEN 和 VPSDEPLOY_WORKER_TOKEN 的示例占位值分别改成两段不同的强随机令牌。可执行 openssl rand -hex 32 两次来生成，不要把令牌提交到 GitHub。

# 容器使用 UID 10001 写入 data 目录
sudo chown -R 10001:10001 data
sudo docker compose up -d --build

从另一台电脑访问 NAS 上的面板时，建议先建立 SSH 隧道：

ssh -L 8787:127.0.0.1:8787 YOUR_USER@YOUR_NAS_IP

然后在本机浏览器打开 http://127.0.0.1:8787，使用 .env 中的管理员令牌登录。Docker / NAS 模式不启用 Windows 本地自动登录。需要 SSH 私钥登录 VPS 时，使用专用私钥并按 Compose 配置 提供只读密钥；密码登录不需要设置私钥文件。
