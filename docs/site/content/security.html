不是生产稳定版

本控制台 v{{version}} 仍处于 Alpha 阶段。Web 管理面板、SSH 自动化与软件安装都涉及高权限操作，建议先在有快照的测试 VPS 上使用，完成自己的部署验收后再考虑扩大使用范围。

管理面板应在哪里运行

推荐 Windows 11 本机 127.0.0.1:8787，或者 Docker / NAS 仅绑定本机环回并使用 SSH 隧道。不要将带免登录的管理 Web API 直接暴露到公网，尤其不要通过反向代理无鉴权开放它。

为什么部署前要审核

每个项目使用固定、可见的步骤。部署前会重新检测 SSH 身份、兼容条件和可能冲突；管理员审阅并明确批准后才启动。AI Worker 仅用于只读诊断脱敏日志，不应该执行它临时生成的系统命令。

管理员密码与凭据

  • 绝不将 root 密码、SSH 私钥、初始管理密码粘贴到 GitHub Issue 或公开文档。
  • Windows SSH 密码可以按需使用系统凭据库；本控制台不能替代 Windows 账户锁屏和主机安全。
  • 面板项目安装后的初始管理员信息只在用户主动查看时经可信 SSH 读取，不应进入普通部署日志。
  • 自建项目安装后生成的初始密码同样只出现在该次任务的部署日志里 —— 看到就立刻保存，日志不会长期保留。
  • 一旦密码出现在聊天、教程截图、Shell 历史或公开仓库，应视为已经泄露，立即更换，并检查近期登录记录。

root 密码登录的风险

开启 root 密码 SSH 务必使用自定义强密码，限制 SSH 防火墙来源 IP，并保留云控制台的恢复方式。密码登录的风险明显高于密钥 / OS Login，生产环境优先用密钥。

网络与证书

公网 HTTPS 服务必须验收证书身份、监听端口和对应防火墙规则。证书签发或续期失败时应保持本机访问并回退，不要临时开放明文管理端口。关闭整台 UFW 不是解决连通性问题的首选办法。

自建项目的边界

  • 物流报价系统：后端只监听 127.0.0.1，公网只暴露 nginx 的 80/443。管理员密码、报价表和每个账号的费率数据都在服务器本地，源码安装默认不带任何数据。
  • 音乐解锁工具：纯静态站，没有后端、没有数据库、不装常驻服务；解密在访问者的浏览器里完成，文件不上传服务器。
  • 两个项目的安装都钉在固定 commit 并校验 SHA-256，不会执行仓库里未经审阅的远程脚本。

Dockge Apps 公网管理风险

Dockge Apps 新安装默认生成服务器公网 IP + 端口直连计划（在下一页明确审批后才执行）。该地址使用未加密 HTTP，而且 Dockge Apps 挂载 Docker Socket，具备主机级管理权限。首次管理员初始化前可能被他人抢先注册，因此强烈建议先在云安全组限制来源 IP；更安全的替代方案是 SSH 隧道或具有认证的 HTTPS 反向代理。
